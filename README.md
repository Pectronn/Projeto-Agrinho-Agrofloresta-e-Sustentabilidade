# Agrofloresta: O Futuro Sustentável

Projeto desenvolvido para o Agrinho 2026 com o objetivo de apresentar a agrofloresta como uma alternativa sustentável para a produção de alimentos e a preservação ambiental.

## Sobre o Projeto

A agrofloresta é um sistema de cultivo que combina árvores, arbustos e culturas agrícolas em uma mesma área, imitando o funcionamento de uma floresta natural. Esse modelo contribui para a conservação do solo, da água e da biodiversidade, ao mesmo tempo em que gera alimentos e renda para os produtores.

O site apresenta:

- O desafio entre produção de alimentos e desmatamento;
- O funcionamento dos Sistemas Agroflorestais (SAFs);
- Os impactos positivos da agrofloresta;
- Um simulador simples de impacto agroflorestal;
- Modo claro e modo escuro.
